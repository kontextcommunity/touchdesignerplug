## 5. Риск-менеджмент
| Риск | Вероятность | Влияние | Как заметить | Как избежать / исправить |
|---|---|---|---|---|
| В нашей версии TD другие имена параметров | средняя | сборка падает | ошибка set_params | брать имена из operator_info, не из видео |
| В видео не видно значение параметра | высокая | результат отличается | нет кадра с панелью | подобрать по картинке, пометить в «Отклонениях» |
| Нет ассета из видео | средняя | блок не собрать | — | замена из раздела «Подготовка» |
| Перегрузка GPU (большое разрешение, feedback, частицы) | средняя | fps падает | Performance Monitor | понизить разрешение, ограничить feedback |
| Линейный рост `absTime.seconds` в выражениях | средняя | сцена «улетает» через время | значения растут | `math.sin` / `math.fmod` |
| Цикл feedback без затухания | средняя | белый экран | яркость растёт | level с brightness < 1 в петле |
| Аудиоустройство отличается | средняя | нет реакции на звук | каналы по нулям | audiofilein как запасной вход |
