# Правила сборки в TouchDesigner

- Строить только внутри workspace COMP (по умолчанию /project1/stage_work), если пользователь не назвал другое место.
- Имена: lowercase_with_underscores, описывающие функцию: audio_in, level_rms, fb_loop, noise_main.
- Финальный визуал всегда заканчивается Null TOP с именем out1.
- Данные текут слева направо, одна цепочка на строку, ~200 px между нодами.
- Разрешение по умолчанию 1920x1080, если не указано иное. Feedback и частицы — не выше разрешения выхода.
- Для любого параметра, который пользователь может менять, в ответе указывать путь к оператору и имя параметра.
- Нативные операторы предпочтительнее GLSL. GLSL — только если оператор не справится за несколько нод.
- Выражения аудио-реактивности: сначала проверить диапазон канала (см. gotchas), потом связывать с параметром.
- После каждого блока — verify. Ошибки и предупреждения не оставлять без объяснения.
- Лёгкий аудио-сигнал: device in → analyze(rms) → filter → math(scale 0..1) → null. Не тянуть лишние ноды.

Источник: Obsidian Vehcadrob/TouchDesigner (Дерево Создания, Группы Проектов), правила сборки.
