# Сборка по туториалу (инструкция из базы знаний)

- Перед сборкой найти инструкцию по названию или теме (search_knowledge) и прочитать её целиком (get_knowledge). Не собирать по памяти.
- Идти по блокам инструкции по порядку. Каждый блок: собрать, verify, потом следующий.
- Значения, помеченные APPROXIMATE или «уточнить», проверить по operator_info и кадру. Отклонения записать в раздел «Отклонения от видео».
- В собранной инструкции (draft → built) каждый блок обязан иметь «Что менять»: оператор.параметр, диапазон, формат, зависимости, что не трогать. Если его нет, инструкцию не сохранять как built, а дописать.
- Аннотации в сети (annotate) делать по knowledge/rules/project-annotation.md на языке чата.
