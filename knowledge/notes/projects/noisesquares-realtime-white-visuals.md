## Главное, что нужно знать про сеть

- Вся сеть — один network из 20–25 нод: шум → null → edge-цепочка → feedback → level → composite(add) → limit (Round) → displace → второй feedback → composite → RGB key → level.
- Визуал регулируется в основном `limit1.quantizepositionstep` (0.18–0.35: мелкая и крупная сетка), `noise1.period` и `level*.opacity` (длина шлейфа).
- Анимация идёт через выражение на `noise1` по Z: `absTime.seconds / 10`.
- Reset петли в видео — клавиша `1` через Keyboard In DAT.

## Что ещё не проверено

- Exponent шума (2.5 по тексту, на кадре 1 во время правки) и разрешение (1280×1280 в финале, на кадре 256×256 во время правки).
- Ось и делитель в анимации 00:25–00:48.
- Главы 02:00–05:42 — только по тексту.

## Как использовать как референс

Нейронка, которая строит сеть, должна сначала прочитать `instruction.md`, затем сверить каждый параметр через operator_info, а не брать его из этого текста. Все расхождения с видео записываются в раздел «Отклонения» инструкции.
